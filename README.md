# SaveProject

**SaveProject**는 유니티 세상 속에서 떨어지는 오류를 피하고,  
프로젝트가 강제 종료되지 않도록 버텨내는 **3인칭 액션 프로젝트**입니다.

플레이어는 Unity 기능을 활용하며 장애물과 낙하물을 피하고,  
메모리 사용량을 관리하며 최대한 오래 생존해야 합니다.

---

## 프로젝트 개요

- **프로젝트명** : SaveProject
- **장르** : 3인칭 액션 / 생존
- **개발 인원** : 팀 프로젝트
- **개발 환경** : Unity, C#

---

## 주요 플레이 요소

- TPS 기반 플레이어 이동
- 오류 낙하물 회피
- Unity 기능 기반 플레이 구조
- 메모리 사용량 및 상태 관리
